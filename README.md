# Brainvibes Configuration System

Repositori ini menyimpan file konfigurasi utama untuk standardisasi dan otomatisasi pengembangan aplikasi berbasis AI pada ekosistem **Gemini CLI**, **Antigravity CLI**, dan **Antigravity IDE**.

## Berkas Utama

1. **[gemini.md](gemini.md) (Otak)**
   * Berisi *Global System Instructions* untuk mengarahkan model kecerdasan buatan (LLM) agar patuh pada aturan interaksi linear, penanganan terminal multi-OS (Windows/Unix), pencegahan bias desain visual (Light/Dark Mode), dan alur siklus hidup otomatis (handover, commit, & YOLO debugging).

2. **[prd-template.md](prd-template.md) (Eksekutor)**
   * Berkas cetak biru *Product Requirements Document* (PRD) 10-poin yang dirancang khusus agar mudah dibaca oleh agen AI. Dilengkapi dengan batasan desain visual (CSS root tokens), aturan path routing adaptif, serta penanda kondisional untuk proyek statis (HTML/CSS) maupun dinamis (SPA/Database).

## Alur Kerja Utama

* **Awal Baru:** Fase inisiasi proyek menggunakan kuesioner interaktif 10 poin untuk menyusun PRD dan peta jalan koding (`todo.md`).
* **Awal Lanjut:** Mode kontinuitas yang mendukung:
  1. *Direct Passive Blueprinting (Dokumentasi Instan):* Membuat dokumentasi pasif berdasarkan file eksisting (sangat optimal untuk tema HTML/CSS sederhana).
  2. *Active Refactoring (Peningkatan Kualitas):* Mengaudit celah kualitas dan memandu wawancara untuk melengkapinya.
* **Baca Error:** Mode penanganan bug YOLO (Zero Compromise) untuk mendeteksi silent visual error, kebocoran tipe data, dan perbaikan massal kebal interupsi terminal.
